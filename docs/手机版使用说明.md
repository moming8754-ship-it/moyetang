# 东方摩耶堂 · 手机版使用说明

> 写给**我自己**看的（一个人用，没有账号、没有云）。
> 手机和电脑是**两个独立的应用**，数据各存各的，靠**同一个 WiFi 里的一次同步**对齐。
> 最后更新：2026-10-29（v2.24.3）

---

## 1. 装它

| 步骤 | 说明 |
|---|---|
| 1 | 拿到 `东方摩耶堂-手机版-v<版本>-Release.apk`（电脑 `D:\东方摩耶堂\` 根目录） |
| 2 | 传到手机（微信文件传输助手 / 数据线 / 局域网都行） |
| 3 | 手机上点开安装 → 允许「安装未知应用」 |
| 4 | **覆盖升级**：直接装，不用卸载 —— 只要是同一台电脑打的包，签名就一样，`versionCode` 也是递增的 |
| 5 | 装完打开，**设置 → 最下面**能看到版本号（跟电脑上那个包一致就是对的） |

⚠️ 三条铁律：

1. **别卸载**！卸载会清掉手机上的应用数据（笔记/待办/图片都在里面）。要换机先做第 4 节的导出。
2. **只在同一台电脑打包**。换电脑后 `debug.keystore` 会变 → 新包签名不同 → 手机报「应用未安装 / 签名不一致」，只能卸载重装（数据没了）。
3. 安卓上的「release 包」是**自用侧载**：签名用的是 Android 工具链的 debug 钥匙，不上应用商店。

---

## 2. 第一次打开

- **不需要登录、不需要网络**。所有数据在手机本地。
- 第一次是空的，这是正常的：手机的数据要**从电脑同步过来**（第 3 节），或者你自己在手机上记。
- 底栏 6 格：首页 / 信息区 / 认知区 / 执行区 / 日程 / 更多（更多里是 技能区 · 档案库 · 设置 · 同步电脑，档案库要电脑那边开开关才会出现）。

---

## 3. 和电脑同步（同一个 WiFi）

**前提**：电脑和手机连的是**同一个路由器 / 同一个 WiFi**（手机开热点给电脑也行，只要在同一网段）。

| 步 | 电脑上 | 手机上 |
|---|---|---|
| 1 | 打开东方摩耶堂 → **设置 → 同步** → 「开始同步」 | — |
| 2 | 出现**二维码**（下面还有 IP + 端口 + 一次性短码） | 「更多」→ **同步电脑** → 扫码 |
| 3 | 等它跑完，会出一张**账单**：补来几条 / 传去几条 / 跳过几条 / 有没有冲突 | 同样能看到账单 |
| 4 | 同步完两端都刷新 | 同左 |

账单上的词：

- **补来** = 电脑有、手机没有 → 进手机
- **传去** = 手机有、电脑没有 → 进电脑
- **跳过** = 两边一样（按 `updatedAt` 比）
- **冲突** = 同一条两边都改过 → 按时间新的赢，**不生成副本**（2026-10-21 拍板）

⚠️ 几个容易踩的：

1. **图片**（`assets/`）也在同步范围内，但一轮最多 8 MB / 12 张，装不下的会写进账单「下次接着传」——**多同步两次就齐了**，不是丢了。
2. 同步前电脑会自动做一次快照（`backups/sync-pre/<时间>/`），出事能整体回退。
3. 手机上**删除**笔记/待办：笔记走墓碑会跨端删；待办不跨端（各删各的）。
4. 第一次同步**先备份一次电脑数据目录**（整目录 zip），这是唯一能整体后悔的办法。

## 4. 导出 / 换机

### 4.1 整份备份（换手机用这个）

| 步 | 手机 |
|---|---|
| 1 | 「更多」→ **设置** → **数据** → 「导出备份」 |
| 2 | 选好存哪（安卓会调到系统文件选择器）→ 存成一个 `.zip` |
| 3 | 换到新手机：装同一个 APK → 设置 → 数据 → 「导入备份」→ 选那个 zip |

导出内容 = 笔记 / 待办 / 信息 / 格言 / 档案 / 倒计时 / 配置 / 图片（`assets/`）。
导入是**整包替换**（会先留旧备份再导），别拿旧备份去覆盖新的。

### 4.2 单篇导出

- 认知区列表 ⋮ → 「存到手机（Markdown）」/「（纯文本）」
- 树笔记：树页 ⋮ → 「存到手机（Markdown）」
- 会存进手机的「下载 / 东方摩耶堂 /」目录（MediaStore，文件管理器能看到）

### 4.3 从电脑拿一篇笔记进手机

三种都行：① 同步（最省事）② 电脑「全部导出」成 `.md` → 传到手机 → 手机上「认知区列表顶部 ⬆ 导入 Markdown」③ 直接在文件管理器里点 `.md` → 用东方摩耶堂打开（见下）

## 5. 文件关联（点 .md 直接打开）

- 手机上用文件管理器点一个 `.md` → 「打开方式」选东方摩耶堂 → 会**新建一篇笔记**（重复打开同一个文件也是新建副本，**不覆盖**已有笔记）
- 打开时会先弹「**已接收：文件名**」；如果紧接着弹红条「读取 Markdown 失败 / 读取安卓待导入文件失败」，把红条原文记下来（这是唯一能定位的线索）
- 电脑上：右键 `.md` → 打开方式 → 东方摩耶堂（安装/免安装版启动时会自己注册；不抢系统默认程序）

## 6. 常见问题

| 症状 | 怎么办 |
|---|---|
| 安装时报「应用未安装 / 签名不一致」 | 上一次装的是**别的电脑**打的包。只能卸载重装 → **先导出备份**（第 4.1 节），否则数据没了 |
| 手机上看不到图片，显示「图片在电脑上」 | 图还没同步过来。再同步一次（一轮有 8 MB / 12 张上限） |
| 同步扫不上码 | ① 确认同一 WiFi（手机开热点给电脑也行）② 电脑上点了「开始同步」没有 ③ 二维码下面有 IP+短码，可以手输兜底 |
| 红条「读取安卓待导入文件失败」 | v2.24.3 已修（release 包的 R8 把 JNI 方法裁掉了）。还出现就说明装的是旧包 |
| 电脑和手机改同一条，谁赢 | 按 `updatedAt` 时间新的赢；**不生成冲突副本** |
| 手机上「档案库」入口不见了 | 电脑上「设置 → 档案区」开关是关的。档案库跟着那个开关走（不是 bug） |

## 7. 版本与回退

- 装之前先看根目录的包名版本号是不是最新的（`版本号` 在文件名里）。
- 想退回旧版本：**不能直接降级安装**（`versionCode` 变小会拒装）→ 卸载 → 装旧包 → 从备份导入数据。
- 每次的包和 SHA256 记在 `进度.md` 的「程序状态」那一格。
