# 东方摩耶堂 · 电脑版使用说明

> 写给**我自己**看的（一个人用，本地文件，不登录、不联网、不部署）。
> 手机版看另一份：`手机版使用说明.md`；两端靠**同一个 WiFi 下的一次同步**对齐。
> 最后更新：2026-10-29（v2.24.3）

---

## 1. 装它 / 启动

| 方式 | 文件 | 特点 |
|---|---|---|
| **免安装**（平时用这个） | `东方摩耶堂-桌面版-v2.24.3-免安装.exe` | 放哪都能跑；**删掉 exe 也不丢数据**（数据不在它旁边）；启动时会顺手注册 `.md` 的「打开方式」 |
| 安装包 | `东方摩耶堂-桌面版-v2.24.3-安装包.exe` | NSIS，装到用户目录、带卸载项；功能完全一样 |

- 第一次打开会弹 **Windows SmartScreen「未知发布者」** → 点「更多信息」→「仍要运行」。原因：自用包没有代码签名证书，**不是病毒**（签名只影响"发布者显示"，不影响功能）。
- 覆盖升级：**直接替换 exe 就行**（或装新安装包），配置和数据都在 `D:\东方摩耶堂`，不受影响。
- ⚠️ 同一个 exe **不要同时开两份** —— 程序有单实例锁，第二份会自己退出（这是防数据打架，不是 bug）。

## 2. 数据在哪（最重要的一节）

**默认数据目录：`D:\东方摩耶堂`** —— **不是**安装目录，也不是 exe 旁边。

| 东西 | 位置 |
|---|---|
| 笔记 | `notes\<id>.json`（文本 / 树各一种） |
| 删除的笔记（有后路，不是硬删） | `notes\_trash\` |
| 被收进档案库的笔记文件 | `notes\_archive\` |
| 待办 / 信息 / 提醒 | `todos.json` / `info.jsonl` / `reminders.json` |
| 奖状 / 格言 / 档案 / 倒计时 / 批注 | `awards.json` / `mottos.json` / `archive.json` / `countdowns.json` / `annotations.json` |
| 图片（**原图永不删**） | `assets\`（uuid 文件名） |
| 自动留档 / 同步前快照 / 导入前备份 | `backups\` |
| 同步状态（设备 id、lastSyncAt、墓碑） | `sync\` |
| 设置 | `config.json` |

三条规矩：

1. **换电脑 / 重装系统**：把整个 `D:\东方摩耶堂` 拷走，程序装好后在「设置 → 数据目录」指回它即可（会问你确认，切换会复制数据）。
2. **卸载程序不会删数据**（数据在数据目录，不在安装目录）。但**别手删 `notes\` / `assets\`**。
3. 每次写文件都是「原子写 + `.bak`」，出问题先看同名 `.bak`（那是上一版）。

## 3. 窗口、快捷键、托盘

| 窗口 | 怎么开 | 说明 |
|---|---|---|
| 主窗 | 双击 exe | 七个区：首页 / 信息区 / 认知区 / 执行区 / 日程 / 技能区 / 档案库 · 设置 |
| **小窗（速记）** | **`Ctrl+Space`**（全局热键，设置里可换） | 无边框、置顶、不占任务栏；适合随手记一句 |
| 专注窗 | 执行区点待办「▶ 开始」 | 番茄钟；结束有二次确认，可暂停 |
| 挂件 | 设置/托盘里开 | **置顶浮窗**，位置记忆；没有"真桌面层"（v2.24 起统一置顶） |

托盘与退出：

- **点关闭按钮 = 收进托盘**（默认，可在设置里改成直接退出）。
- 真退出：托盘图标右键 →「退出」，或界面左下角 `quit`。
- 托盘图标 **6:00 / 18:00 自动换**（白天/夜晚两套，跨时间点会自己刷新）。

## 4. 同步（电脑是服务端）

手机上的数据是**独立的一份**，靠同步对齐。电脑这边负责"开服务"。

| 步 | 操作 |
|---|---|
| 1 | 确认电脑和手机在**同一个 WiFi**（手机开热点给电脑也行） |
| 2 | 设置 → **同步** → 「开始同步」→ 出现**二维码**（下面还有 IP + 端口 + 一次性短码） |
| 3 | 手机扫码（或手输 IP + 短码）→ 两边自动跑完 |
| 4 | 看**账单**：补来 / 传去 / 跳过 / 冲突 |

- **补来** = 对方有我没有；**传去** = 我有对方没有；**跳过** = 一样；**冲突** = 同一条两边都改过 → **按 `updatedAt` 取新的，不生成副本**（2026-10-21 拍板）。
- 每次同步前会自动做快照：`backups\sync-pre\<日期-时间>\` —— 出问题能整体回退。
- 图片一轮最多 8 MB / 12 张，装不下的记进账单「下次接着传」，**多同步几次就齐**。
- ⚠️ 已知老坑：同步可能会把 `notes\_archive\` 洗空（现在有"档案自愈"，重启/同步结束会从 `archive.json` 快照补回）。动同步前先备份。

## 5. 文件关联（双击 .md 直接进）

- 免安装版**每次启动**会把当前 exe 注册成 `.md / .markdown / .txt` 的「打开方式」（HKCU，**不抢系统默认程序**）。
- 用法：右键 `.md` → 打开方式 → 东方摩耶堂。
- 行为：**每次都新建一篇笔记**（重复打开同一文件也是新建副本，**不覆盖**）。
- 想让默认程序是它：Windows 设置 → 应用 → 默认应用 → 按文件类型选。

## 6. 备份 / 导出 / 导入

| 做什么 | 在哪 | 说明 |
|---|---|---|
| **整包备份** | 设置 → 导出备份 | 选路径存 `.zip`；内容是笔记/待办/信息/格言/档案/倒计时/配置/图片 |
| **整包恢复** | 设置 → 导入备份 | **整包替换**（后端会先把当前数据留一份到 `backups\`，后悔能导回来） |
| 单篇导出 | 认知区列表某篇的 `⋮` → 导出 Markdown / 纯文本 | 另存为对话框；树笔记导出成缩进文本 |
| 批量导出 | 认知区左栏「⬆ 全部导出…」 | 选文件夹，每篇一个 `.md`，重名自动加 `-2` |
| 批量导入 | 认知区左栏「⬇ 导入…」 | 可多选，每个文件一篇新笔记 |
| 导出时带图 | 自动 | 真用到、本地真有的图会复制到 `<笔记名>.assets\` 并改成相对路径 |

## 7. 界面上的几个习惯（新手最容易懵）

- **认知区左栏可以收起**（边缘那颗小箭头），收起后编辑区吃满整幅。
- **编辑辅助栏可自定义**：设置 → 编辑辅助栏 → 排序/移除/添加/恢复默认；**手机竖排条读同一份配置**（撤销/重做/插图三颗固定保留）。
- **树画布**：拖空白处平移；**Ctrl+滚轮**缩放（普通滚轮不缩放，免得误触）；双击节点改字，Enter 加同级、Tab 加子级。
- **待办标记写法**：正文里写 `-[]文字`（不是 `- [ ]`，也不认缩进），执行区会自动出现；勾选状态存在待办里，**不改你的正文**。
- 笔记正文是**你手写的**，程序不会替你改字（除了你主动点格式按钮）。

## 8. 常见问题

| 症状 | 原因 / 怎么办 |
|---|---|
| 双击 exe **闪一下就没了**（事件日志 `0xc0000409`） | WebView2 的 profile 坏了 / 或 exe 放在**带低完整性标签的目录**里。v2.24.3 起会自动重建（启动自愈）；还不行跑 `notes-app\tools\fix-webview-profile.ps1`，并把 `%LOCALAPPDATA%\com.dongfangmoyetang.notes\startup.log` 发我 |
| 装了新版反而打不开 | 先用 `fix-webview-profile.ps1` 清一次 WebView2 缓存（只改名不删）；再不行看 `startup.log` 最后几行 |
| SmartScreen 拦 | 「更多信息」→「仍要运行」；自用包无代码签名，正常现象 |
| 换电脑后打的新包，手机装不上 | 新电脑的 `debug.keystore` 变了 → 签名不一致。**手机上的数据先导出**，卸载再装，最后导入备份 |
| 开了 dev 却起不来 | 成品版开着会占单实例锁 → dev 静默退出。反过来也一样：一个实例只允许一个 |
| 托盘里找不到 / 关不掉 | 点关闭只是收托盘；真退出走托盘右键「退出」或左下 `quit` |
| 数据目录搬走后图显示不出来 | 设置里改数据目录会复制数据；外部手动搬的话要搬**整个目录**（含 `assets\`） |
| 想回退旧版本 | exe 直接换回旧文件即可（数据格式向后兼容）；安装包装的也可以再装旧的 |
